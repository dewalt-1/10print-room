How it works

A line with a number is stored as part of the program. A line without a number runs straight away.
Try: 10 PRINT CHR$(205.5+RND(1));:GOTO 10, Return, then RUN.

Keys

Escstop the program (RUN/STOP)
Shift + lettergraphic characters: Shift+M ╲, Shift+N ╱, Shift+Q ●, Shift+S ♥
Arrow keysmove the cursor anywhere. Change a line on screen and press Return to store it again.
Backspacedelete. Shift+Backspace inserts a space.
Ctrl+Lclear the screen
Cmd/Ctrl+Vpaste a whole program

Commands

RUNstart the program
LISTshow it (LIST 10-50)
NEWforget it
SAVE "NAME"keep it in this browser
LOAD "NAME"get it back. LOAD "$" lists what you saved.

Handing in

link copies a web address that opens your program; paste it anywhere. save downloads it as a text file.

The language

PRINT, GOTO, IF…THEN, FOR…TO…STEP / NEXT, GOSUB / RETURN, INPUT, GET, DIM, READ / DATA / RESTORE, DEF FN, ON…GOTO, POKE / PEEK, END, STOP, CONT, REM. Functions: RND INT ABS SGN SQR SIN COS TAN ATN EXP LOG CHR$ ASC LEN LEFT$ RIGHT$ MID$ STR$ VAL TAB( SPC(. The screen starts at address 32768: POKE 32768,81 puts a ball in the top left corner.
